# Developer Portfolio Website

A modern and fully responsive personal portfolio website built using WordPress with custom CSS and JavaScript enhancements. This project showcases professional skills, projects, resume, and contact information through a clean and interactive user interface.

 ##Features

* Fully responsive design for mobile, tablet, and desktop
* Custom WordPress theme customization
* Interactive UI using custom JavaScript
* Smooth scrolling and modern animations
* Project showcase section
* Skills and experience section
* Resume download option
* Contact form integration
* Optimized performance and clean layout
  
## Technologies Used

* WordPress
* HTML5
* CSS3
* JavaScript
* Elementor / Custom Theme Customization
* Git & GitHub

## Customization

This website includes:

* Custom CSS for advanced styling and responsive layouts
* Custom JavaScript for animations and interactive functionality
* Personalized sections including About, Skills, Projects, and Contact

## GitHub Integration

The project is version-controlled using Git and pushed to GitHub for easy collaboration, backup, and deployment.

## Purpose

The main purpose of this portfolio website is to create a professional online presence to showcase development skills, projects, and achievements.
